# Radar Senor

Firmware Unterschiede!

Firmware < v1.5.3 (z. B. v1.5.2): Benötigt eine Baudrate von 256.000 und nutzt den Pin OT2 für die serielle Übertragung (TX).

Firmware ≥ v1.5.3: Benötigt eine Baudrate von 115.200 und nutzt den Pin OT1 für die serielle Übertragung (TX). 


Achtung: Beim günstigen LD2420-V2.0 sind auch ältere Varrianten im Umlauf. Meine z.B. hatte die Version 1.6.1 und hat damit entgegen der Aussage des Händlers OT1 als TX Pin und eine BaudRate von 115200.
